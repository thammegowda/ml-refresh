[#sol-ex-losses-nll.solution]
====
For Gaussian noise with fixed stem:[\sigma],
stem:[-\log p(y\mid\hat y)=(y-\hat y)^2/(2\sigma^2)+\log\sigma+\tfrac12\log2\pi]. Only the
squared residual depends on stem:[\hat y], so maximum likelihood minimizes MSE. For Laplace
noise, stem:[-\log p(y\mid\hat y)=|y-\hat y|/b+\log(2b)], so the prediction-dependent part is
MAE. The scale changes the gradient size but not the optimum when fixed.
====

[#sol-ex-losses-kl-js-focal.solution]
====
Focal loss multiplies BCE by stem:[(1-p_t)^\gamma]. When stem:[p_t\approx1], the multiplier is
near zero, so easy examples contribute little. When stem:[p_t] is small, the multiplier is near
one, so hard examples keep a cross-entropy-like signal. Forward KL, stem:[\KL(p\Vert q)],
averages over the target and punishes missing target mass. Reverse KL, stem:[\KL(q\Vert p)],
averages over the model and is more willing to focus on one mode. Jensen-Shannon is symmetric
because it averages stem:[\KL(p\Vert m)] and stem:[\KL(q\Vert m)] with the same midpoint
stem:[m=(p+q)/2].
====
