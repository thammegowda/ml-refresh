[#sol-ex-activations-saturation.solution]
====
For sigmoid, stem:[\sigma'(x)=\sigma(x)(1-\sigma(x))]. As stem:[x\to\infty],
stem:[\sigma(x)\to1]; as stem:[x\to-\infty], stem:[\sigma(x)\to0]. Either way the product goes
to 0. Since stem:[\tanh'(x)=1-\tanh^2(x)] and stem:[\tanh(x)\to\pm1], tanh also saturates.
ReLU has slope 0 for negative inputs, so a unit that is always negative never updates from the
loss signal. Leaky ReLU replaces that 0 slope by stem:[\alpha], leaving a path for gradients.
====

[#sol-ex-activations-derivatives.solution]
====
For stem:[s=\sigma(x)=1/(1+e^{-x})],
stem:[s'=e^{-x}/(1+e^{-x})^2=s(1-s)], whose largest value is stem:[1/4] at stem:[s=1/2].
Using stem:[\tanh x=(e^x-e^{-x})/(e^x+e^{-x})] gives stem:[\tanh'(x)=1-\tanh^2(x)], largest
at 0 with value 1. SiLU is a product, so
stem:[(x\sigma(x))'=\sigma(x)+x\sigma(x)(1-\sigma(x))]. Softplus has derivative
stem:[e^x/(1+e^x)=\sigma(x)]. The test `test_elementwise_activation_derivatives_match_finite_differences`
checks these formulas against central differences.
====
