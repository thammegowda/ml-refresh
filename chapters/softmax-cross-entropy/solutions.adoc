[#sol-ex-softmax-cross-entropy-jacobian.solution]
====
Let stem:[Z=\sum_k e^{z_k}] and stem:[p_i=e^{z_i}/Z]. For stem:[i=j], quotient rule gives
stem:[(e^{z_i}Z-e^{z_i}e^{z_i})/Z^2=p_i(1-p_i)]. For stem:[i\ne j], only the denominator
changes, giving stem:[-e^{z_i}e^{z_j}/Z^2=-p_i p_j]. Therefore
stem:[J=\diag(\vp)-\vp\vp^\T]. A row sum is stem:[p_i-p_i\sum_jp_j=0], matching shift
invariance.
====

[#sol-ex-softmax-cross-entropy-gradient.solution]
====
Using log-softmax,
stem:[L=-\sum_i y_i z_i+\sum_i y_i\log\sum_j e^{z_j}]. Since stem:[\sum_i y_i=1], this is
stem:[-\vy^\T\vz+\log\sum_j e^{z_j}]. Differentiating gives stem:[-y_j+p_j]. With temperature,
all logits inside softmax are stem:[z_j/T], so the chain rule multiplies the gradient by
stem:[1/T].
====
