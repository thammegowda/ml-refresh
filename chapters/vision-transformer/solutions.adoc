[#sol-ex-vision-transformer-convolution.solution]
====
Let a flattened patch be stem:[\vx_{r,c} \in \R^{P^2C}] and the embedding weight be
stem:[\mW_E \in \R^{P^2C \times d}]. Reshape each column of stem:[\mW_E] into a
stem:[P \times P \times C] kernel. A stride-stem:[P] convolution places that kernel on exactly
the pixels of one patch and computes the same dot product stem:[\vx_{r,c}\mW_E + \vb_E].
Because stride equals patch size, windows do not overlap. The test compares the two arrays.
====

[#sol-ex-vision-transformer-forward.solution]
====
For stem:[8 \times 8] images and stem:[2 \times 2] patches, the patch grid is
stem:[4 \times 4], so there are 16 patch tokens. Class-token mode sends 17 tokens into the
encoder and reads token 0. Mean-pooling mode sends 16 tokens and averages them after the
encoder. The classification head is shared, so both modes return logits shaped
stem:[B \times \text{classes}]. The test runs both modes and checks finite stem:[3 \times 3]
logits on a seeded synthetic batch.
====
